# solarpowermonitor
Here’s a concise version under 350 characters:  **Renewable Energy Microgrid Battery Scheduler** — A C++ project simulating 24‑hour solar microgrid performance. Models solar input, 5 device loads, and a 2220 Wh battery with 30% DoD limit. Runs 96 quarter‑hour steps, logging CHARGE, DISCHARGE, IDLE, or BLACKOUT states with SoC and uptime metrics.
